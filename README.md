# なんでもいいよ 🍽️

「今日何食べたい？」「なんでもいい」を解決する、スマホ向けのごはん抽選 Web アプリ。

## 機能
- **内食 / 外食モード**：外食は「ジャンル」と「お店」の両方を登録でき、抽選時に絞り込めます
- **出やすさ 7 段階**：`除外 / −2 / −1 / ±0 / +1 / +2 / +3`（重み 0, ×0.25, ×0.5, ×1, ×2, ×4, ×8）
- **気分タグで絞り込み**（AND 条件）
- **最近食べたものを出にくく**：履歴にある項目の確率を 1/4 に（日数は設定可能）
- **抽選演出**：🎡 ルーレット / 🎰 スロット / 🎱 ガチャ / 🎲 おまかせ
  - 当選はまず重み付き乱数で決め、演出はその結果に着地するよう逆算して動かします
  - 確率が低い項目が当たると ✨レア / 🌈超レア 演出
- 決定後：レシピ検索 / Google マップ / 共有、履歴に記録
- サンプルプリセット入り、バックアップ（コピー）と復元
- PWA：ホーム画面に追加すると全画面・オフラインで動作

データはブラウザの localStorage にだけ保存されます（サーバーなし）。

## 開発

```sh
npm install
npm run dev      # 開発サーバー（--host 付きなので同じ LAN のスマホから確認可）
npm test         # 抽選ロジックのユニットテスト
npm run build    # 型チェック + 本番ビルド（dist/）
```

## 公開（GitHub Pages）
`main` に push すると `.github/workflows/deploy.yml` がビルドして公開します。
初回のみリポジトリの **Settings → Pages → Source** を **GitHub Actions** にしてください。

## 構成
```
src/
  lottery.ts      重み計算・抽選・レア度（テストあり）
  store.ts        状態管理と localStorage 保存
  presets.ts      サンプルデータ
  sound.ts        Web Audio による効果音
  fx/             抽選演出（roulette / slot / gacha / confetti）
  views/          画面（決める / リスト / 履歴 / 設定）
```
